# Product
Haunted Repo: a static web app that turns a public GitHub repository's open issues into monsters in a haunted house.
Bigger and older issues make bigger monsters. Beginner-friendly issues are marked. Clicking a monster opens the issue.
Audience: maintainers (see backlog at a glance), new contributors (find a starting point), people evaluating a project.
Hackathon: Kiroween 2026, Frankenstein track. All submission text is in English.
